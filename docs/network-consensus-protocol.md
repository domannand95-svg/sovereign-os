# Network Consensus Protocol

## Overview

The Sovereign OS network consensus protocol implements the Raft distributed consensus algorithm to maintain a consistent replicated state machine across a cluster of peers. The protocol guarantees that committed log entries are applied in the same order on every healthy node while tolerating individual node failures.

---

# Architecture

```
               +-----------------------+
                              |    Client Requests    |
                                             +-----------+-----------+
                                                                        |

                                                                                                                                                         +----------------+
                                                                                                                                                                            |      |      |
                                                                                                                                                                                  AppendEntries|      |      |Heartbeat
                                                                                                                                                                                                     |      |      |
                                                                                                                                                                                                              +---------+      |      +---------+
                                                                                                                                                                                                                       |                |                |
                                                                                                                                                                                                                                v                v                v
                                                                                                                                                                                                                                 +---------------+ +---------------+ +---------------+
                                                                                                                                                                                                                                  | Follower Node | | Follower Node | | Follower Node |
                                                                                                                                                                                                                                   +---------------+ +---------------+ +---------------+

                                                                                                                                                                                                                                                                                                                                                                                    ```

                                                                                                                                                                                                                                                                                                                                                                                    ---

                                                                                                                                                                                                                                                                                                                                                                                    # Cluster Roles

                                                                                                                                                                                                                                                                                                                                                                                    ## Leader

                                                                                                                                                                                                                                                                                                                                                                                    Responsibilities:

                                                                                                                                                                                                                                                                                                                                                                                    - Accepts client commands.
                                                                                                                                                                                                                                                                                                                                                                                    - Appends commands to the replicated log.
                                                                                                                                                                                                                                                                                                                                                                                    - Replicates entries to followers.
                                                                                                                                                                                                                                                                                                                                                                                    - Tracks replication progress.
                                                                                                                                                                                                                                                                                                                                                                                    - Advances the commit index after majority acknowledgment.
                                                                                                                                                                                                                                                                                                                                                                                    - Sends periodic heartbeat messages.

                                                                                                                                                                                                                                                                                                                                                                                    ---

                                                                                                                                                                                                                                                                                                                                                                                    ## Follower

                                                                                                                                                                                                                                                                                                                                                                                    Responsibilities:

                                                                                                                                                                                                                                                                                                                                                                                    - Responds to AppendEntries requests.
                                                                                                                                                                                                                                                                                                                                                                                    - Persists replicated log entries.
                                                                                                                                                                                                                                                                                                                                                                                    - Rejects stale terms.
                                                                                                                                                                                                                                                                                                                                                                                    - Applies committed entries.
                                                                                                                                                                                                                                                                                                                                                                                    - Starts an election after heartbeat timeout.

                                                                                                                                                                                                                                                                                                                                                                                    ---

                                                                                                                                                                                                                                                                                                                                                                                    ## Candidate

                                                                                                                                                                                                                                                                                                                                                                                    Responsibilities:

                                                                                                                                                                                                                                                                                                                                                                                    - Initiates elections.
                                                                                                                                                                                                                                                                                                                                                                                    - Requests votes.
                                                                                                                                                                                                                                                                                                                                                                                    - Becomes leader upon receiving a quorum.
                                                                                                                                                                                                                                                                                                                                                                                    - Reverts to follower if a higher term is observed.

                                                                                                                                                                                                                                                                                                                                                                                    ---

                                                                                                                                                                                                                                                                                                                                                                                    # Election Flow

                                                                                                                                                                                                                                                                                                                                                                                    1. Election timeout expires.
                                                                                                                                                                                                                                                                                                                                                                                    2. Node increments current term.
                                                                                                                                                                                                                                                                                                                                                                                    3. Vote requests are broadcast.
                                                                                                                                                                                                                                                                                                                                                                                    4. Majority vote is obtained.
                                                                                                                                                                                                                                                                                                                                                                                    5. Candidate becomes leader.
                                                                                                                                                                                                                                                                                                                                                                                    6. Leader immediately sends heartbeat messages.

                                                                                                                                                                                                                                                                                                                                                                                    ---

                                                                                                                                                                                                                                                                                                                                                                                    # AppendEntries Flow

                                                                                                                                                                                                                                                                                                                                                                                    1. Leader receives a client command.
                                                                                                                                                                                                                                                                                                                                                                                    2. Entry is appended locally.
                                                                                                                                                                                                                                                                                                                                                                                    3. Entry is transmitted to followers.
                                                                                                                                                                                                                                                                                                                                                                                    4. Followers validate:
                                                                                                                                                                                                                                                                                                                                                                                       - current term
                                                                                                                                                                                                                                                                                                                                                                                          - previous log index
                                                                                                                                                                                                                                                                                                                                                                                             - previous log term
                                                                                                                                                                                                                                                                                                                                                                                             5. Followers append valid entries.
                                                                                                                                                                                                                                                                                                                                                                                             6. Followers acknowledge replication.
                                                                                                                                                                                                                                                                                                                                                                                             7. Leader advances the commit index after majority confirmation.
                                                                                                                                                                                                                                                                                                                                                                                             8. Committed entries are applied to the state machine.

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Heartbeat Protocol

                                                                                                                                                                                                                                                                                                                                                                                             Heartbeat packets contain:

                                                                                                                                                                                                                                                                                                                                                                                             - current term
                                                                                                                                                                                                                                                                                                                                                                                             - leader identifier
                                                                                                                                                                                                                                                                                                                                                                                             - commit index

                                                                                                                                                                                                                                                                                                                                                                                             Heartbeats:

                                                                                                                                                                                                                                                                                                                                                                                             - prevent unnecessary elections
                                                                                                                                                                                                                                                                                                                                                                                             - synchronize commit progress
                                                                                                                                                                                                                                                                                                                                                                                             - verify cluster liveness

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Log Replication

                                                                                                                                                                                                                                                                                                                                                                                             Each log entry contains:

                                                                                                                                                                                                                                                                                                                                                                                             - index
                                                                                                                                                                                                                                                                                                                                                                                             - term
                                                                                                                                                                                                                                                                                                                                                                                             - command
                                                                                                                                                                                                                                                                                                                                                                                             - serialized payload

                                                                                                                                                                                                                                                                                                                                                                                             Replication guarantees:

                                                                                                                                                                                                                                                                                                                                                                                             - ordered delivery
                                                                                                                                                                                                                                                                                                                                                                                             - deterministic replay
                                                                                                                                                                                                                                                                                                                                                                                             - durability before acknowledgment

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Conflict Resolution

                                                                                                                                                                                                                                                                                                                                                                                             Followers reject inconsistent histories when:

                                                                                                                                                                                                                                                                                                                                                                                             - previous index is missing
                                                                                                                                                                                                                                                                                                                                                                                             - previous term differs

                                                                                                                                                                                                                                                                                                                                                                                             Recovery process:

                                                                                                                                                                                                                                                                                                                                                                                             1. Leader decrements nextIndex.
                                                                                                                                                                                                                                                                                                                                                                                             2. Retries AppendEntries.
                                                                                                                                                                                                                                                                                                                                                                                             3. Divergent entries are overwritten.
                                                                                                                                                                                                                                                                                                                                                                                             4. Replication resumes.

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Commit Index

                                                                                                                                                                                                                                                                                                                                                                                             The commit index advances only after:

                                                                                                                                                                                                                                                                                                                                                                                             - a majority of replicas acknowledge the entry
                                                                                                                                                                                                                                                                                                                                                                                             - the entry belongs to the current leader's term

                                                                                                                                                                                                                                                                                                                                                                                             Committed entries become immutable.

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Safety Guarantees

                                                                                                                                                                                                                                                                                                                                                                                             The protocol guarantees:

                                                                                                                                                                                                                                                                                                                                                                                             - Leader Completeness
                                                                                                                                                                                                                                                                                                                                                                                             - Election Safety
                                                                                                                                                                                                                                                                                                                                                                                             - Log Matching
                                                                                                                                                                                                                                                                                                                                                                                             - State Machine Safety
                                                                                                                                                                                                                                                                                                                                                                                             - Linearizable writes

                                                                                                                                                                                                                                                                                                                                                                                             ---

                                                                                                                                                                                                                                                                                                                                                                                             # Failure Recovery

                                                                                                                                                                                                                                                                                                                                                                                             Supported failure scenarios include:

                                                                                                                                                                                                                                                                                                                                                                                             - leader crashes
                                                                                                                                                                                                                                                                                                                                                                                             - follower crashes
                                                                                                                                                                                                                                                                                                                                                                                             - network partitions
                                                                                                                                                                                                                                                                                                                                                                                             - delayed messages
                                                                                                                                                                                                                                                                                                                                                                                             - duplicate packets
                                                                                                                                                                                                                                                                                                                                                                                             - node restarts

                                                                                                                                                                                                                                                                                                                                                                                             Consensus is restored automatically after quorum is re-established.
