# Engineering Glossary

This glossary defines common terminology used throughout the Sovereign OS documentation.

## Architecture

The documented structure, responsibilities, interfaces, and constraints of the system.

## Capability Firewall

The governance boundary that prevents research concepts from being treated as production functionality without formal promotion.

## Event Log

The append-only history of state transitions used to reconstruct system state.

## Registry

The structured repository of validated system state.

## Snapshot

A compact representation of validated state used to accelerate recovery.

## Determinism

The property that identical inputs produce identical outputs and recoverable system state.

## Research Document

A document describing exploratory work, hypotheses, or future investigations. Research documents do not imply implementation.

## Production Document

A document describing implemented or approved architecture.

## ADR

Architecture Decision Record documenting significant engineering decisions.

## RFC

Request for Comments proposing future architectural or implementation changes.
